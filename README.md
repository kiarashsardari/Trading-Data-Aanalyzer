# README پروژه تحلیل استراتژی‌ها

##این پروژه فعلا درحال گسترش، ولی کاملا قابل اجراست

## معرفی کلی
این پروژه برای تحلیل عملکرد استراتژی‌های معاملاتی بر اساس داده‌های ثبت‌شده طراحی شده است.  
هدف کلی، فراهم کردن ابزارهایی برای خواندن داده، دسته‌بندی استراتژی‌ها و محاسبه شاخص‌های مختلف مانند نرخ برد و... است.

## وضعیت پروژه
این پروژه در حال تکمیل است.  
هر بخش پس از کامل شدن و قابل استفاده بودن، به‌روزرسانی می‌شود.  
هر به‌روزرسانی به‌صورت جداگانه و مستقل قابل استفاده است؛ یعنی توابع و قابلیت‌های اضافه‌شده نیازی به منتظر ماندن برای بخش‌های دیگر ندارند.

## ساختار کلی
- `dataset.py`: تبدیل داده اولیه به فرمت قابل استفاده.
- `main.py`: توابع اصلی تحلیل و گزارش‌گیری.
- `test.py`: اجرای آزمایشی توابع.
- `my_dataset.csv`: نمونه داده ورودی/خروجی.

## استفاده کلی
در هر مرحله، می‌توانید از توابعی که تاکنون تکمیل شده‌اند به‌صورت مستقل استفاده کنید.  
فقط کافی است فایل `test.py` را ران کنید
با اضافه شدن قابلیت‌های جدید، همین README نیز به‌روزرسانی خواهد شد.

## به‌روزرسانی‌ها
- هر زمان بخشی از پروژه کامل و قابل استفاده شود، همان بخش آپدیت می‌شود.
- هر آپدیت جداگانه قابل استفاده است.
- جزئیات بیشتر در نسخه‌های بعدی اضافه خواهد شد.

> توجه: این نسخه صرفاً یک نمای کلی است و ممکن است با تکمیل پروژه تغییر کند.
